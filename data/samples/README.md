# Sample data: contacts and draft appointments

`contacts.json` holds 20 fictional organisations as JSContact cards (RFC 9553); `events.json` holds 5 draft appointments as JSCalendar 2.0 events. Same structure as before; the events point to the cards through `freesynergy.net:cardUid`.

All names, addresses, telephone numbers and links are invented. Domains follow RFC 2606 (`example.org`, `example.com`, `example.net`, `example.invalid`). Any resemblance to real organisations is accidental. Use these files for demos and tests only.
