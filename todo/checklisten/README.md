# Abhak-Listen je Programm

Jede Liste zeigt, was in einem Programm **erledigt** ist und was **noch offen** ist.

- `- [x]` = erledigt, mit Beleg (Commit, Tag oder Bild) in Klammern.
- `- [ ]` = **TODO**, also noch offen.
- **GRUNDSACHE** = gehört zum Monatsziel (ADR 0087 Punkt 7): Das Programm startet, kann einfache Dinge und lässt sich beenden; dazu kommen die Frontends.
- **SPÄTER** = gehört nicht zu diesem Monat.

Abgehakt wird nur mit Beleg. Erledigte Punkte bleiben stehen und werden nicht gelöscht. Jede Änderung am Programm zieht ihre Liste mit (Workflow `doku-mitziehen`). Später wandern diese Listen nach fs-tasks.
