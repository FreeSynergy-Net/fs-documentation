# Matrix Spaces - Beschreibung

> [Matrix Spaces](../index.md)

## Zweck

- Ein Space gruppiert Räume und Personen; wählt man einen Space aus, erscheint nur, was dazugehört [S3].
- Räume werden mit `m.space.child` einem Space zugeordnet; die Gegenrichtung nutzt `m.space.parent` [S1] (Richtung und Bedeutung: [offen]).

## Space anlegen

- Web und Desktop: auf "+ Create a space" klicken [S3].
- iOS und Android: auf das Space-Symbol tippen und "create" wählen [S3].
- Ein öffentlicher oder privater Space kann gewählt werden [S3].

## Räume und Personen hinzufügen

- Nach dem Anlegen können Personen eingeladen und neue oder bestehende Räume hinzugefügt werden [S3].
- Raum anlegen: Ein "+"-Button steht neben dem Space-Namen in der linken Leiste [S4].
- Menüwege zum Hinzufügen bestehender Räume: [offen].

## Zugangsregel

- Beim Hinzufügen eines Raums kann "Space members" gewählt werden, damit nur Space-Mitglieder beitreten können [S2].
