## Menü-Inventar (Element)

| Ort | Eintrag | Wirkung | Quelle |
|---|---|---|---|
| Linke Leiste | "+ Create a space" (Web/Desktop) | Legt einen Space an | S3 |
| Linke Leiste, mobil | Space-Symbol, dann "create" (iOS/Android) | Legt einen Space an | S3 |
| Linke Leiste, neben dem Space-Namen | "+"-Button | Legt einen Raum im Space an | S4 |
| Raumeinstellungen | "Security & Privacy" | Zugriffseinstellungen eines Raums | S2 |
| Raumzugang | "Private (invite only)" | Nur eingeladene Personen können beitreten | S2 |
| Raumzugang | "Space members" | Nur Space-Mitglieder können beitreten | S2 |
