# Matrix Spaces - Zustände

> [Matrix Spaces](../index.md)

## Zugriffszustände

- Raum auf "Space members" beschränkt: Eine Person außerhalb des Space kann ohne Einladung nicht beitreten [S2].
- Beitritt ohne Einladung in einem verschlüsselten Raum: Die frühere Historie wird nicht angezeigt [S2].
- Raum "Private (invite only)": nur ausdrücklich eingeladene Personen können beitreten [S2].
