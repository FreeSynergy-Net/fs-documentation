# Google Groups - Beschreibung

> [Google Groups](../index.md) · Beschreibung

## Zweck

- Eine Gruppe hat eine eigene E-Mail-Adresse, Mitglieder, Rollen und Unterhaltungen [S2][S3].
- Sichtbarkeit: Gruppenmitglieder, Organisationsmitglieder oder alle im Web [S2].
- Beitritt: nur eingeladene Nutzer oder Beitrittsoptionen für Organisation/öffentlich [S2].

## Grenzen und Bedingungen

- Konten von Organisationen (Work/School) erhalten zusätzliche Optionen (nur Organisation sichtbar, Collaborative Inbox, Auto-Antworten, Umgang mit verdächtigen Nachrichten) [S2].
- Öffentliche Sichtbarkeit und externe Mitglieder hängen von der Freigabe durch den Admin ab [S2].
- Gruppen aus dem Verzeichnis zu verbergen braucht eine Admin-Einstellung [S2].
- Kinderkonten können auf keinem Weg hinzugefügt werden [S3].
- Personen ohne Google-Konto können eingeladen, aber nicht direkt zu @googlegroups.com-Gruppen hinzugefügt werden [S3].
