# Google Groups

## Was es ist

Google Groups verwaltet hinter einer Gruppen-E-Mail-Adresse Mitglieder, Rollen und Regeln für Nachrichten [S2][S3][S6].

## Bemerkenswerte Ideen

- Mitglieder können direkt hinzugefügt oder eingeladen werden; eine eingeladene Person muss die Einladung annehmen. Beim direkten Hinzufügen wird die Rolle Mitglied, Manager oder Besitzer gewählt [S3].
- Berechtigungen werden je Funktion mit Schiebereglern gesetzt und können Standard- oder eigenen Rollen zugewiesen werden, außer Ansicht der Mitgliederliste und Mitgliederverwaltung [S6].
- Admins können Besitzern das Recht zum Ansehen von Mitgliedern und Unterhaltungen nicht entziehen, andere Besitzerrechte aber einschränken [S2].
- Einige Optionen gibt es nur für Konten von Organisationen (Work/School) oder wenn ein Admin sie freigibt [S2].
