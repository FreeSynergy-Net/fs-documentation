# Microsoft 365 Groups

## Was es ist

Microsoft-365-Gruppen sind Zusammenarbeitsgruppen mit Besitzern und Mitgliedern; eine neue Gruppe stellt ihren Mitgliedern ein gemeinsames Postfach, einen Kalender, eine Dokumentbibliothek und weitere Ressourcen bereit [S2][S6].

## Bemerkenswerte Ideen

- Die Mitgliedschaft ist die Zugriffssteuerung: wer in die Gruppe aufgenommen wird, erhält Zugriff auf deren gemeinsame Ressourcen [S2].
- Drei Rollen: Besitzer verwalten Mitgliedschaft und Einstellungen, Mitglieder nutzen Ressourcen, Gäste werden von außerhalb der Organisation eingeladen [S2][S6].
- Lebenszyklus: Ablaufrichtlinien schicken Besitzern Erinnerungen 30, 15 und 1 Tag vor Ablauf; nicht verlängerte Gruppen werden gelöscht [S2].
- Löschen ist 30 Tage umkehrbar (Soft-Delete); ein Admin kann die Gruppe in diesem Zeitraum wiederherstellen [S4].
- Eine Gruppe ohne Besitzer bekommt automatisch einen neuen Besitzer [S6].
