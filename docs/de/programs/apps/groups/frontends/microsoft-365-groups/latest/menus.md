# Microsoft 365 Groups - Menüs

> [Microsoft 365 Groups](../index.md) · Menüs

Menü-Inventar aus den Dokumenten. Vollständiger Navigationsbaum: [offen].

## Nutzer-Gruppenseite

- Gruppenseite im Konto-Portal: "Gruppen, die ich besitze" und "Gruppen, in denen ich bin", mit Option zum Anlegen [S1].
- Gruppenseite: Schaltfläche (+) für Personen, "Details bearbeiten", "Gruppe löschen" [S1].

## Admin-Center

- Teams & Gruppen -> Aktive Teams & Gruppen -> Gruppe auswählen -> Einstellungsbereich [S3].
- Reiter des Einstellungsbereichs: Mitgliedschaft (Besitzer und Mitglieder, Hinzufügen und X) [S3]; Einstellungen (Kopien in Postfächer, externe Absender) [S3].
- "Name und Beschreibung bearbeiten" [S3].
- Gruppen -> Gelöschte Gruppen -> "Gruppe wiederherstellen" [S4].

## Entra-Admin-Center

- Entra ID -> Gruppen -> Alle Gruppen -> Neue Gruppe, mit Gruppentyp, Name, E-Mail-Adresse, Beschreibung, Mitgliedschaftstyp, Besitzern, Mitgliedern [S5].
- Ausgewählte Gruppe: Mitglieder, Besitzer, Eigenschaften, Gruppenmitgliedschaften, Löschen [S5].

## Outlook im Web

- Seite gelöschte Gruppen, unter Gruppen -> Gruppen verwalten -> Gelöscht, mit Reiter Wiederherstellen [S4].
