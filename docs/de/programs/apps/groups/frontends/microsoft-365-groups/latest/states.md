# Microsoft 365 Groups - Zustände

> [Microsoft 365 Groups](../index.md) · Zustände

## Gruppenzustände

- Soft-gelöscht: 30 Tage wiederherstellbar, danach endgültig gelöscht [S4].
- Wiederhergestellt: Mitglieder und Inhalte kommen zurück, dies kann bis zu 24 Stunden dauern [S4].
- Wiederhergestellt, Mail noch nicht betriebsbereit: mindestens eine Stunde warten, sonst Fehler 550 5.1.10 RecipientNotFound [S4].
- Ohne Besitzer: ein automatisches System weist einen neuen Besitzer zu [S6].
- Abgelaufen: Besitzer erhalten Erinnerungen; nicht verlängerte Gruppen werden gelöscht [S2].

## Zugriffszustände

- Für Mitgliederverwaltung nötige Admin-Rolle: Groups Administrator oder User Administrator [S5].
- Delegierter Admin: kann diese Gruppen nicht verwalten [S2].
- Besitzergrenze erreicht (100) [S2].
- Gruppenanlage durch Admin-Richtlinie eingeschränkt: Nutzer kann dann etwa keine SharePoint-Seite, kein Planner und kein Teams anlegen [S2].
