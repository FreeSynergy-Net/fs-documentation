# Nextcloud Circles

## Was es ist

Nextcloud Circles (App-ID `circles`) ist eine Gruppenfunktion innerhalb von Nextcloud, um Ressourcen mit einer benannten Personengruppe zu teilen. Im Benutzerhandbuch von Nextcloud 35 heißt die Funktion "Teams" und wird in einer eigenen Teams-App verwaltet [S1]. Die App-Store-Seite führt die App als nicht mehr aktiv über den App-Store verteilt und als Teil der Nextcloud-Server-Pakete [S2]. Die Lizenz laut Quelltextdatei ist AGPL-3.0-or-later [S3]; die App-Store-Seite selbst nennt keine Lizenz [S2].

## Bemerkenswerte Ideen

- Ein Circle kann lokale Konten, Gruppen, E-Mail-Adressen und andere Circles als Mitglieder aufnehmen; eine Rolle, die einer Gruppe oder einem Circle zugewiesen wird, gilt für alle ihre Mitglieder [S1].
- Vier feste Rollen (Mitglied, Moderator, Admin, Besitzer), genau ein Besitzer pro Circle [S1].
