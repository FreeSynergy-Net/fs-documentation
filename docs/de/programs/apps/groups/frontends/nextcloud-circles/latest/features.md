# Nextcloud Circles - Funktionen

> [Nextcloud Circles](../index.md)

## Mitgliedschaft

- Mitglieder: lokale Konten, Gruppen, E-Mail-Adressen, andere Circles [S1].
- Mitglieder einer Gruppe oder eines Circles erhalten die Rolle, die der Gruppe oder dem Circle zugewiesen wurde [S1].

## Teilen

- Mitglieder können auf Ressourcen zugreifen, die mit dem Circle geteilt wurden [S1].
- Weitere Freigabeziele (z. B. Dateien- oder Kalenderfreigabe in der Oberfläche): [offen].

## Rollen

- Mitglied, Moderator, Admin, Besitzer; ein Besitzer pro Circle [S1].

## Nicht durch abgerufene Quellen belegt

- Einladungen und Bestätigung von Einladungen: [offen].
- Circle verlassen: [offen].
- Circle löschen: [offen].
- Gelöschten Circle wiederherstellen: [offen].
- Verschachtelungstiefe und Grenzen: [offen].
