## Zugriffszustände

- Mitglied ohne Recht an einer Ressource: sieht nur Ressourcen, die mit dem Circle geteilt wurden [S1]. Genaue Meldung in der Oberfläche: [offen].
- Besitzer: genau einer pro Circle; die Besitzerrolle kann nur ein Mitglied haben [S1].
