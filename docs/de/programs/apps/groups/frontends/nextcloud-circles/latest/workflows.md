# Nextcloud Circles - Arbeitsabläufe

> [Nextcloud Circles](../index.md)

Feste IDs W1 bis W7. Schritte als "Nutzer tut X -> Programm zeigt Y".

## W1 Gruppe anlegen

- Ziel: ein neuer benannter Circle mit Mitgliedern.
- Voraussetzung: [offen] (welches Konto oder welche App-Rechte nötig sind).
- Schritte: Nutzer klickt auf "+" neben Teams im linken Menü [S1] -> Programm fragt nach einem Teamnamen [S1] -> Nutzer gibt Namen ein -> Programm öffnet die Konfigurationsansicht [S1] -> Nutzer fügt Mitglieder hinzu [S1].
- Fehler: [offen].
- Rückgängig: [offen].

## W2 Gruppe einer Obergruppe zuordnen

- Ziel: ein Circle wird Mitglied eines anderen Circles.
- Voraussetzung: [offen].
- Schritte: Circles können als Mitglieder hinzugefügt werden [S1] -> genaue Oberflächenschritte: [offen].
- Fehler und Rückgängig: [offen].

## W3 Mitglied direkt aufnehmen

- Ziel: Person, Gruppe, E-Mail-Adresse oder Circle direkt hinzufügen.
- Voraussetzung: [offen].
- Schritte: Nutzer fügt lokales Konto, Gruppe, E-Mail-Adresse oder Circle als Mitglied hinzu [S1] -> Programm wendet die Rolle der Gruppe oder des Circles auf alle ihre Mitglieder an [S1] -> genaue Oberflächenschritte: [offen].
- Fehler und Rückgängig: [offen].

## W4 Mitglied entfernen oder Austritt

- Ziel: ein Mitglied wird entfernt oder verlässt den Circle.
- Voraussetzung: [offen].
- Schritte: [offen] (Entfernen und Austritt nicht durch abgerufene Quellen belegt).
- Fehler und Rückgängig: [offen].

## W5 Einladen, annehmen oder ablehnen

- Ziel: eine Person einladen, die annimmt oder ablehnt.
- Voraussetzung: [offen].
- Schritte: [offen] (Einladungsablauf auf keiner abgerufenen Seite bestätigt).
- Fehler und Rückgängig: [offen].

## W6 Rolle ändern

- Ziel: ein Mitglied wird Mitglied, Moderator, Admin oder Besitzer.
- Voraussetzung: [offen] (wer Rollen ändern darf).
- Schritte: Nutzer öffnet das Drei-Punkte-Menü neben einem Nutzer [S1] -> Nutzer ändert die Rolle [S1] -> Programm übernimmt sie [offen].
- Regel: nur ein Besitzer pro Circle [S1].
- Fehler: [offen]. Rückgängig: [offen].

## W7 Gruppe löschen (und wiederherstellen)

- Ziel: Circle entfernen; wiederherstellen, falls unterstützt.
- Voraussetzung: [offen].
- Schritte: [offen].
- Fehler und Rückgängig: [offen].
