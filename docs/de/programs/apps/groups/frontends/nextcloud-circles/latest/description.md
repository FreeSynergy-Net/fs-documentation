# Nextcloud Circles - Beschreibung

> [Nextcloud Circles](../index.md)

## Zweck

- Ein Circle (in Nextcloud 35 "Teams" genannt) ist eine benannte Gruppe von Mitgliedern zum Teilen [S1].
- Mitglieder können lokale Konten, Gruppen, E-Mail-Adressen oder andere Circles sein [S1].
- Ein Mitglied kann nur auf Ressourcen zugreifen, die mit dem Circle geteilt wurden, und sieht die übrigen Mitglieder [S1].

## Circle anlegen

- Auf das "+" neben Teams im linken Menü klicken, dann einen Teamnamen eingeben; danach öffnet sich eine Konfigurationsansicht [S1].
- In der Konfigurationsansicht werden Mitglieder hinzugefügt [S1].
- Die Teams-App verwaltet Circles; Kontakte übernimmt sie nur dort, wo die Oberfläche der Teams-App deaktiviert ist [S1].

## Rollen

- Mitglied, Moderator, Admin, Besitzer [S1].
- Pro Circle ist nur ein Besitzer erlaubt [S1].
- Was Moderator und Admin im Einzelnen dürfen: [offen] (nicht im abgerufenen Handbuchtext).

## Optionen

- Einladungs- und Mitgliedschaftsregeln, Sichtbarkeit, Beitritt zu anderen Circles, Passwortschutz: [offen] (auf keiner abgerufenen Seite bestätigt).
