# Discourse Groups - Beschreibung

> [Discourse Groups](../index.md)

## Umfang
- Eine Gruppe ist eine benannte Menge von Mitgliedern innerhalb einer Discourse-Seite [S5].
- Besitzer verwalten die Mitgliedschaft der Gruppen, denen sie zugewiesen sind. Sie können keine neuen Gruppen anlegen [S1].
- Admins legen Gruppen an und ernennen Besitzer [S1, S5]. Moderatoren dürfen Gruppen nur anlegen, wenn die Einstellung `moderators_manage_groups` aktiv ist [S5].
- Die Sichtbarkeit einer Gruppe betrifft nur das Verzeichnis. Der Zugriff auf Inhalte richtet sich nach der Kategorie-Sicherheit [S2].

## Offene Punkte
- Lizenz des Programms: [offen] (nicht gegen das offizielle Repository geprüft).
- Verschachtelung von Gruppen, Löschen und Umbenennen: [offen] (nicht in S1-S5 behandelt).
- In S1 gibt es einen strittigen Kommentar, ob normale Mitglieder die Besitzer sehen können. Verhalten: [offen].
