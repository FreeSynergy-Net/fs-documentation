# Discourse Groups - Zustände

> [Discourse Groups](../index.md)

## Leer
- Gruppe ohne Mitglieder: [offen].
- Gruppe ohne Besitzer: Beitrittsanfragen lassen sich nicht aktivieren; die Einstellung wird abgelehnt [S3, S4].

## Laden
- [offen] (keine Quelle beschreibt Ladezustände).

## Fehler
- Beitrittsanfragen ohne Besitzer werden mit der Meldung "You cannot allow membership requests without any owners" abgelehnt. S4 nennt diese Meldung aus einem Thread von 2017; dieser Thread wurde nicht selbst gelesen [S4].
- Eine Beitrittsanfrage kommt möglicherweise nicht an, wenn kein Besitzer existiert [S4].

## Teilweise
- Die Option für Beitrittsanfragen ist ausgegraut, solange die Sichtbarkeit nicht "Everyone" oder "Logged on users" ist [S3].
- Eine Änderung der Sichtbarkeit wird erst mit "Save Changes" gespeichert [S3].

## Zugriff verweigert
- Gruppe im Verzeichnis ausgeblendet, wenn die Sichtbarkeit nicht "Everyone" ist [S2].
- Mitgliederliste ausgeblendet, wenn sie auf Besitzer, Mitglieder oder Moderatoren beschränkt ist [S2].
- Der Zugriff auf Inhalte richtet sich nach der Kategorie-Sicherheit, nicht nach der Gruppensichtbarkeit [S2].

## Offene Punkte
- Ob eine private Gruppe eine Anfrage-Schaltfläche zeigt: [offen] (ein verwandter Thread wurde nur als Suchtreffer gesehen).
