# Discourse Groups - Funktionen

> [Discourse Groups](../index.md)

## Gruppeneinstellungen
- Name, vollständiger Name und Beschreibung der Gruppe [S5].
- Besitzer und Mitglieder, beim Anlegen festgelegt [S5].
- Mitgliedschaft: Zugriff, automatische Aufnahme und Flair [S5].
- Sichtbarkeit: wer die Gruppe sehen kann (Standard "Everyone") [S2, S5].
- Sichtbarkeit der Mitgliederliste (Standard "Everyone"); sie lässt sich auf Besitzer, Mitglieder und Moderatoren beschränken [S2].
- Einstellungen für Erwähnen, Nachrichten und Benachrichtigungen [S5].

## Mitgliedschaftsoptionen
- Freier Beitritt: Nutzer nehmen sich selbst über eine Schaltfläche "Join" auf [S2, S3].
- Beitrittsanfragen: Nutzer senden eine Anfrage an die Besitzer, optional mit Anfragevorlage [S2, S3].
- Freier Austritt: Nutzer verlassen die Gruppe über "Leave" [S2].
- Beitrittsanfragen brauchen mindestens einen Besitzer [S2, S4].

## Funktionen für Besitzer
- Besitzer erhalten Beitrittsanfragen [S2].
- Besitzer fügen Mitglieder hinzu und entfernen sie [S1].
- Besitzer können ab Discourse 3.1 weitere Besitzer hinzufügen; entfernen können sie nur Mitarbeiter [S1].

## Offene Punkte
- Besitzerrechte über die Mitgliedschaft hinaus: [offen] (S2 nennt keine).
- Suche, Sortierung und Seitenaufteilung im Gruppenverzeichnis: [offen].
