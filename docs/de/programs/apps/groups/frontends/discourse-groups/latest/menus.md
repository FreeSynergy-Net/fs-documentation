# Discourse Groups - Menüs

> [Discourse Groups](../index.md)

## Gruppenseite
- Einstieg: Seitenleistenlink "Groups" (unter "More") oder der Pfad /g [S5].
- Schaltfläche "New Group" (oben rechts) [S5].
- Die Gruppenseite zeigt für Gruppen mit Beitrittsanfragen eine Schaltfläche "Request" [S3].

## Gruppenansicht
- Schaltfläche "Join" bei Gruppen mit freiem Beitritt [S2].
- Schaltfläche "Request" bei Gruppen mit Beitrittsanfragen [S2, S3].
- Schaltfläche "Leave" bei Gruppen mit freiem Austritt [S2].
- Pfad Manage -> Membership -> Access (unter /g/<gruppenname>) für Zugriffseinstellungen [S3].

## Reiter Members (Admin und Besitzer)
- Schraubenschlüssel neben einem Mitglied: "Make Owner", Besitz entziehen, Nutzer entfernen [S1, S2].
- Schaltfläche "+ Add Members" für Besitzer [S4].
- Schild-Symbol "Owner" markiert Besitzer in der Liste [S1].

## Offene Punkte
- Vollständiger Menübaum der Gruppeneinstellungen: [offen].
- Menü zum Löschen oder Archivieren einer Gruppe: [offen].
