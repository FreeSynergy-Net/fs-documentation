# Discourse Groups

## Was es ist
Discourse-Gruppen sind Mitgliederlisten innerhalb der Forensoftware Discourse. Admins ernennen Besitzer je Gruppe, und Besitzer verwalten die Mitgliedschaft dieser Gruppe [S1]. Sichtbarkeits- und Zugriffseinstellungen legen fest, wer eine Gruppe sehen, betreten oder um Aufnahme bitten kann [S2].

## Bemerkenswerte Ideen
Eine Beitrittsanfrage geht an die Gruppenbesitzer, die sie mit Annehmen- und Ablehnen-Links erhalten [S2].
