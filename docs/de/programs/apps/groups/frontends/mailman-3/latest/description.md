# Mailman 3 - Beschreibung

> [Mailman 3](../index.md)

## Umfang
- Nutzer treten Listen bei und verlassen sie über die Informationsseite der Liste [S1].
- Jede Liste hat eigene Besitzer und Moderatoren, je Liste zugewiesen [S1, S2].
- Site-Administratoren betreiben die Software; ein Superuser-Konto ist der Seiteninhaber mit Zugriff auf alle Listen und Domains [S2].
- Die offizielle Doku sagt, dass der Leitfaden für Listenbesitzer und Site-Administratoren "noch nicht vollständig" ist [S3].
