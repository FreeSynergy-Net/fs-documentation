# Mailman 3 - Menüs

> [Mailman 3](../index.md)

## Informationsseite der Liste
- Abschnitt zum Abonnieren: Adresse und optionalen Anzeigenamen wählen, dann absenden [S1].
- Abonnier-Felder am Seitenende, um ohne Konto abonnieren zu können [S1].
- Abo-Abschnitt mit Schaltfläche zum Abmelden [S1].
- Link "sign up" zum Anlegen eines Kontos [S1].
- Hilfsadresse "<liste>-owner" für Abo- oder Einstellungsänderungen, die der Nutzer nicht selbst machen kann [S1].

## Nutzermenü
- Menü unter dem Benutzernamen, Eintrag "Mailman settings" [S1].
- Direkte Abo-URL führt zur selben Einstellungsseite [S1].
