# Mailman 3 - Arbeitsabläufe

> [Mailman 3](../index.md)

## W1 Liste anlegen
- Ziel: [offen]. In S1-S3 ist kein Schritt zum Anlegen einer Liste beschrieben.

## W2 Liste unter einer Obergruppe verschachteln
- Ziel: [offen]. In S1-S3 nicht belegt.

## W3 Mitglied aufnehmen (abonnieren)
- Ziel: ein Nutzer abonniert eine Liste.
- Voraussetzung: die Liste ist bekannt; ein Konto ist optional [S1].
- Schritte: Nutzer öffnet die Informationsseite der Liste -> meldet sich optional an -> wählt Adresse und optionalen Anzeigenamen im Abo-Abschnitt -> sendet ab [S1].
- Ohne Konto: Nutzer nutzt die Abonnier-Felder am Seitenende [S1].
- Admin oder Moderator fügt ein Mitglied hinzu oder genehmigt eine Anfrage: [offen].
- Fehler: [offen].
- Rückgängig: siehe W4.

## W4 Mitglied entfernen oder Austritt
- Ziel: ein Nutzer erhält die Liste nicht mehr.
- Schritte: Nutzer meldet sich an, um die Adresse zu belegen -> öffnet den Abo-Abschnitt -> klickt Abmelden [S1].
- Besitzer entfernt ein Mitglied: [offen].
- Rückgängig: erneut abonnieren über W3.

## W5 Abo oder Einladung bestätigen
- Beitritt: keine separate Bestätigungs-E-Mail beschrieben [S1].
- Bestätigung ist nötig, um den Besitz einer Adresse nachzuweisen, etwa bei einem bestehenden Abo [S1].
- Ablauf der Einladung: [offen].

## W6 Rolle oder Einstellung ändern
- Rollen: Listenbesitzer betreuen eine Liste; Moderatoren prüfen Beiträge vor der Zustellung; Site-Administratoren betreuen die Software [S1].
- Rollen werden je Liste vergeben und brauchen kein Superuser-Konto [S2].
- Nutzer ändert eigene Zustellungseinstellungen: Nutzermenü -> "Mailman settings" -> Einstellung ändern [S1].
- Besitzer oder Moderator einer Liste wechseln: [offen].

## W7 Liste löschen (und wiederherstellen)
- Ziel: [offen]. In S1-S3 nicht belegt.
