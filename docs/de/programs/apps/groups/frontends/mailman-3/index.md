# Mailman 3

## Was es ist
Mailman 3 ist Software für Mailinglisten. Nutzer abonnieren Listen und verwalten ihre eigenen Zustellungseinstellungen [S1]. Rollen werden je Liste vergeben: Listenbesitzer betreuen eine Liste, Moderatoren prüfen Beiträge, und Site-Administratoren betreuen die Software [S1, S2].

## Bemerkenswerte Ideen
Zustellungseinstellungen wirken in Schichten: Einstellung je Liste überschreibt die je Adresse, diese überschreibt die globale Einstellung [S1].
