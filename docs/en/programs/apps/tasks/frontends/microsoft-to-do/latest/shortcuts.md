# Microsoft To Do (Windows) - Keyboard shortcuts

> [Microsoft To Do](../index.md) · [menus](menus.md) · [workflows](workflows.md)

Source: https://support.microsoft.com/en-us/todo/using-keyboard-shortcuts-in-microsoft-to-do , retrieved 2026-11-16. The page states: "You can use keyboard shortcuts on Windows 10". It names no Windows 11 or Mac shortcuts, so this list is marked **Windows 10** throughout. Other shortcut sources (search excerpts for Windows 11) are not used here.

| Keys | Action | Platform (per page) |
|------|--------|---------------------|
| Ctrl+N | Add a new task | Windows 10 |
| Ctrl+L | Create a new list | Windows 10 |
| Ctrl+T | Add task to My Day | Windows 10 |
| Ctrl+D | Complete task | Windows 10 |
| Ctrl+F | Search | Windows 10 |
| Ctrl+V | Paste | Windows 10 |
| Ctrl+R | Sync now | Windows 10 |
| Ctrl+1 | Open sidebar in minified view | Windows 10 |

## Not documented (`[offen]`)

- Windows 11 and Mac equivalents.
- Moving between tasks by keyboard, opening a task, deleting a task, setting due dates: no shortcut named in a read source.
- Whether the shortcut list is complete.
