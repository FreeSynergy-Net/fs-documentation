Sources: see the source table in [index](../index.md), retrieved 2026-11-16. Platform: named per entry; the menu bar of the Windows client is `[offen]`, since no read page lists it. Menu names come from help text in quotes; where a page shows a name only in a screenshot, the entry is `[offen]`.

## Menu inventory (named in read sources)

- **Smart lists** (sidebar)
  - My Day (welcome page, My Day article)
  - Important: starred tasks (sort and search article, Important entry)
  - Planned: tasks with due date or reminder (search excerpt of the Planned article; page not opened)
  - All, Completed, Assigned to me, Flagged Email, Due Today: named in a search excerpt of the settings article only; `[offen]` as menu entries
- **List menu** (three dots, top right of the list)
  - Sort by: Importance, Due date, Added to My Day, Alphabetically, Creation date
- **Task detail view**
  - Add due date: Today, Tomorrow, Next week, Pick a date
  - Remind me: Later today, Tomorrow, Next week, Pick a date & time
  - Add step ("+ Add step"), Save, Done (notes)
  - Pick a category (categories)
  - Assign (assigning in shared lists, What's new 1.62)
  - Share icon (top of the task window)
- **Share menu**
  - Create invitation link, Copy link
  - Manage access: toggle "Limit access to current members"
  - Stop sharing (red button)
- **Search**: magnifying glass next to the username
