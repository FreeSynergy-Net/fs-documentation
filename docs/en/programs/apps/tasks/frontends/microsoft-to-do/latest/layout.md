# Microsoft To Do (Windows) - Structure and UI/UX

Status: `[offen]` for the window layout. The help pages name menus and buttons, but their layout is shown only in screenshots, which were not read. The structure below is therefore limited to what the text names.

## Named regions (from the help text)

- **Sidebar** with the smart lists (My Day; further smart lists are named in search excerpts only) and the user's own lists. The sidebar can be minimised: Ctrl+1 (Windows 10 shortcut page).
- **List view**: tasks of one list, with the list menu (three dots) at the top right. The sort option "Sort by" sits in that menu.
- **Task detail view**: opened by clicking a task. It holds the buttons "Add due date", "Remind me", the steps, the notes, the tags and the categories. The Share icon is at the top of the task window (Share a task list article, Outlook.com page).
- **Search field**: opened with the magnifying glass next to the username (sort and search article).
