# Vikunja - Keyboard shortcuts

> [Vikunja](../index.md) · [menus](menus.md) · [workflows](workflows.md)

Source: https://vikunja.io/help/accessibility (keyboard reference), retrieved 2026-11-16. The page names Mac equivalents as `Cmd`. The list is the page's own; no other source was checked.

| Keys | Action |
|------|--------|
| Ctrl+K / Cmd+K | Open search (also command palette) |
| Ctrl+E / Cmd+E | Show or hide the menu |
| ? | Open the keyboard shortcut reference |
| g then o | Go to Overview |
| g then u | Go to Upcoming |
| g then p | Go to Projects |
| g then a | Go to Labels |
| g then m | Go to Teams |
| g then l | Switch to List view (inside a project) |
| g then t | Switch to Table view (inside a project) |
| g then k | Switch to Kanban view (inside a project) |
| g then g | Switch to Gantt view (inside a project) |
| j | Highlight next task (List view) |
| k | Highlight previous task (List view) |
| Enter | Open highlighted task (List view) |
| t | Mark task done or undone |
| Shift+T | Mark done and return to where the task was opened |
| a | Assign a user |
| l | Add labels |
| d | Change due date |
| Alt+R / Shift+R | Manage reminders |
| e | Edit description |
| p | Change priority |
| c | Change colour |
| f | Add attachment |
| r | Edit related tasks |
| m | Move to another project |
| s | Toggle favourite |
| u | Open the task's project |
| Ctrl+S / Cmd+S | Save |
| Delete / Backspace | Delete the task |
| . | Copy task identifier (press twice for identifier and title, three times to add the URL) |
| Ctrl+. / Cmd+. | Copy task URL |

## Notes

- `Tab` moves focus out of the Markdown editor (accessibility page).
- On Safari, `Tab` skips links by default (accessibility page).
- Not keyboard-accessible per the page: Kanban card reordering, manual List reordering, renaming a Kanban bucket.
- Shortcuts for Gantt, Table, Kanban operations beyond the view switch: `[offen]`.
