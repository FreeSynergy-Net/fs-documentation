# Matrix Spaces - Menus

## Menu inventory (Element)

| Place | Item | Effect | Source |
|---|---|---|---|
| Left panel | "+ Create a space" (Web/Desktop) | Creates a space | S3 |
| Left panel, mobile | Space icon, then "create" (iOS/Android) | Creates a space | S3 |
| Left panel, next to space name | "+" button | Creates a room in the space | S4 |
| Room settings | "Security & Privacy" | Access settings of a room | S2 |
| Room access | "Private (invite only)" | Only invited people can join | S2 |
| Room access | "Space members" | Only members of the space can join | S2 |
