# Matrix Spaces - Description

> [Matrix Spaces](../index.md)

## Purpose

- A space groups rooms and people; selecting a space shows only what belongs to it [S3].
- Rooms are linked to a space with `m.space.child`; the reverse link uses `m.space.parent` [S1] (direction and semantics: [offen]).

## Creating a space

- Web and Desktop: click "+ Create a space" [S3].
- iOS and Android: tap the space icon and select "create" [S3].
- Public or private space can be chosen [S3].

## Adding rooms and people

- After creating a space, people can be invited and new or existing rooms added [S3].
- Room creation: a "+" button sits next to the space name in the left panel [S4].
- Menu paths for adding existing rooms: [offen].

## Access rule

- When adding a room, "Space members" can be selected so that only space members can join [S2].
