## Admin center

- Teams & groups -> Active teams & groups -> select group -> settings pane [S3].

- "Edit name and description" [S3].
- Groups -> Deleted groups -> "Restore group" [S4].

- Entra ID -> Groups -> All groups -> New group, with group type, name, email address, description, membership type, owners, members [S5].
- Selected group: Members, Owners, Properties, Group memberships, Delete [S5].
