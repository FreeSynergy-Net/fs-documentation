# Microsoft 365 Groups - Description

> [Microsoft 365 Groups](../index.md) · Description

## Purpose

- A group bundles shared resources: Outlook group inbox and calendar, SharePoint library, Planner, OneNote, Teams [S2].
- The creator becomes owner and member [S1][S6].
- Group type is set at creation and cannot be changed later; other group types are distribution, security and mail-enabled security groups [S1][S5][S6].

## Limits

- Up to 100 owners per group [S2].
- A user can create up to 250 groups and be owner of up to 7,000 [S2].
- More than 1,000 members are possible; 1,000 can be in group conversations at the same time [S2].
- File storage: 1 TB plus 10 GB per subscribed user; group mailbox 50 GB [S2].
- Delegated administrators (partners acting for a customer) cannot create or manage these groups [S2].

## Privacy

- Groups are public by default; private groups hide content from non-members and require owner approval to join [S7].
- Privacy can also be set by a sensitivity label at creation [S2]. Whether privacy can be changed afterwards: [offen] (the help page does not list it as editable [S1]).
