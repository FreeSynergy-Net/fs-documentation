# Nextcloud Circles - Description

> [Nextcloud Circles](../index.md)

## Purpose

- A circle (called "Teams" in Nextcloud 35) is a named group of members used for sharing [S1].
- Members can be local accounts, groups, email addresses or other circles [S1].
- A member can only access resources shared with the circle and can see the other members [S1].

## Creating a circle

- Click the "+" beside Teams in the left menu, then enter a team name; a configuration screen opens next [S1].
- From the configuration screen, members are added [S1].
- The Teams app manages circles; Contacts handles them only where the Teams app interface is disabled [S1].

## Roles

- Member, Moderator, Admin, Owner [S1].
- Only one Owner is allowed per circle [S1].
