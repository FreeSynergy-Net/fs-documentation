# Mailman 3 - Description

> [Mailman 3](../index.md)

## Scope
- Users join and leave lists through the list's information page [S1].
- Each list has its own owners and moderators, assigned per list [S1, S2].
- Site administrators run the software; a superuser account is the site owner with access to all lists and domains [S2].
- The official docs state that the guide for list owners and site administrators "is not yet complete" [S3].
