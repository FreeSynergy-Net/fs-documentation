# Google Groups - Description

> [Google Groups](../index.md) · Description

## Purpose

- A group has its own email address, members, roles and conversations [S2][S3].
- Visibility options: group members, organization members or anyone on the web [S2].
- Joining: invited users only, or organization/public join options [S2].

## Limits and conditions

- Work or school accounts get extra options (organization-only visibility, Collaborative Inbox, auto replies, suspicious-message handling) [S2].
- Public visibility and external members depend on the admin enabling them [S2].
- Hiding groups from the directory requires an admin setting [S2].
- Child accounts cannot be added by any method [S3].
- Users without a Google account can be invited but not added directly to @googlegroups.com groups [S3].
