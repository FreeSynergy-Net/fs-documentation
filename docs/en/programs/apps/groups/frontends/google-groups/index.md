# Google Groups

> Category: [groups](../../index.md)

## What it is

Google Groups manages members, roles and message rules behind a group email address [S2][S3][S6].

## Notable ideas

- Members can be added directly or invited; an invitee must accept before joining. When adding directly, the adder picks member, manager or owner [S3].
- Permissions are set per function with sliders and can be given to default or custom roles, except member list viewing and member management [S6].
- Admins cannot remove an owner's rights to view members or conversations, but can limit other owner rights [S2].
- Several options exist only for work or school accounts or when an admin enables them [S2].
