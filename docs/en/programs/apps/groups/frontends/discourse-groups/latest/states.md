# Discourse Groups - States

> [Discourse Groups](../index.md)

## Empty
- Group without members: [offen].
- Group without owners: membership requests cannot be enabled; the setting is refused [S3, S4].

## Loading
- [offen] (no source describes loading states).

## Error
- Enabling membership requests without any owner is refused with an error, "You cannot allow membership requests without any owners". S4 cites this message from a 2017 thread; it was not read directly [S4].
- A join request may not be delivered when no owner exists [S4].

## Partial
- Request option greyed out unless visibility is "Everyone" or "Logged on users" [S3].
- Visibility change does not save until "Save Changes" is clicked [S3].

## Access denied
- Group hidden from the directory when visibility is set to something other than "Everyone" [S2].
- Member list hidden when limited to owners, members or moderators [S2].
- Content access depends on category security, not on group visibility [S2].
