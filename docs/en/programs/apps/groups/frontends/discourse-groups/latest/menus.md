# Discourse Groups - Menus

> [Discourse Groups](../index.md)

## Groups page
- Entry: sidebar link "Groups" (under "More"), or the path /g [S5].
- Button "New Group" (top right) [S5].
- Groups page shows a "Request" button for groups that allow requests [S3].

## Group page
- Button "Join" for free-join groups [S2].
- Button "Request" for groups with membership requests [S2, S3].
- Button "Leave" for groups that allow free leaving [S2].
- Path Manage -> Membership -> Access (at /g/<groupname>) for access settings [S3].

## Members tab (admin and owner)
- Wrench icon beside a member: "Make Owner", remove ownership, remove user [S1, S2].
- "+ Add Members" button for owners [S4].
- Shield "Owner" icon marks owners in the list [S1].
