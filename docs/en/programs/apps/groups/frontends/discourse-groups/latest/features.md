# Discourse Groups - Features

> [Discourse Groups](../index.md)

## Group settings
- Name, full name and bio of the group [S5].
- Owners and members, set when creating a group [S5].
- Membership: access, automatic membership and flair [S5].
- Visibility: who can see the group (default "Everyone") [S2, S5].
- Visibility of the member list (default "Everyone"); it can be limited to owners, members and moderators [S2].
- Mentioning, messaging and notification settings [S5].

## Membership options
- Free joining: users add themselves with a Join button [S2, S3].
- Membership requests: users send a request to owners, with an optional request template [S2, S3].
- Free leaving: users can leave with a Leave button [S2].
- Membership requests need at least one owner [S2, S4].

## Owner features
- Owners receive membership requests [S2].
- Owners add and remove members [S1].
- Owners can add other owners from Discourse 3.1 on; only staff can remove them [S1].

## Open points
- Owner permissions beyond membership: [offen] (S2 names none).
- Directory search, sorting and paging of groups: [offen].
